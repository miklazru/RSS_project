# Семантическая фильтрация новостей — роль 4

## Что реализовано

Заглушка TopicMatcher заменена семантическим поиском на модели
sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2.

Движок:
- сравнивает описание темы с заголовком и описанием статьи;
- поддерживает русские и английские тексты;
- работает со статьями без описания;
- возвращает косинусное сходство и причину совпадения;
- сохраняет эмбеддинги статей в кэше по article.id;
- пересчитывает эмбеддинг при изменении текста статьи;
- кэширует эмбеддинги тем;
- ограничивает каждый кэш 2000 записями;
- загружает модель локально и выполняет вычисления на CPU.

Контракт ArticleData, FilterData, MatchResult и метод match() сохранены.

## Установка

Из корня проекта:

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements-dev.txt
python -m scripts.download_minilm
```

Для скачивания модели нужен интернет.
Веса сохраняются в models/multilingual-minilm и не входят в Git.

По умолчанию приложение использует эту папку.
Другой локальный путь можно указать через TOPIC_MODEL_PATH.

## Проверка

После скачивания модели:

```bash
python -m pytest -q
```

На локальном окружении автора: 69 passed.

## Запуск без обращений модели к HuggingFace

```bash
HF_HUB_OFFLINE=1 TRANSFORMERS_OFFLINE=1 uvicorn app.main:app --reload
```

Документация API: http://127.0.0.1:8000/docs

Эти настройки отключают обращения библиотек модели к HuggingFace,
но не отключают интернет для сборщика RSS.

## Пороги

Совпадение определяется условием score >= threshold.

Можно задать threshold отдельно для каждого фильтра.
Если он не задан, используется DEFAULT_TOPIC_THRESHOLD из app/config.py.

Сходство не является вероятностью релевантности.
По умолчанию используется порог 0.5. Его можно изменить для каждого фильтра. На проверенных примерах оптимальные значения различались между темами; повышение порога уменьшает число совпадений, понижение — увеличивает. Значение 0.5 проверено в демонстрационном сценарии про космос.


## Ручная проверка приложения

Создан отдельный пользователь, подписанный на тестовый канал.

Тема:
«Космические исследования, спутники и запуски ракет».

Порог: 0.5.

Результаты:
- русская статья о запуске спутника: совпадение, score ≈ 0.756;
- английская статья о запуске спутника: совпадение, score ≈ 0.717;
- пост про пекарню отсутствует в отфильтрованной ленте;
- после перезапуска с offline-настройками новый пост о полёте
  к Луне обработан: совпадение, score ≈ 0.698;
- фильтр, подписка и ранее сохранённые статьи пережили перезапуск.

У совпадений присутствуют тема, оценка сходства и порог в reasons.

## Ограничения и интеграция

- Модель обрабатывает первые 128 токенов объединённого текста:
  сначала заголовок, затем описание.
- Кэш находится в памяти и заполняется заново после перезапуска.
- Порог следует проверять для конкретной темы.
- Старые сохранённые совпадения после замены модели автоматически
  не пересчитываются. Для проверки нужен новый фильтр либо
  отдельная процедура пересчёта.
- Для Docker необходимо включить скачанную модель в образ или
  смонтировать её и указать TOPIC_MODEL_PATH.
  Текущая локальная проверка не подтверждает готовность Docker-образа.
